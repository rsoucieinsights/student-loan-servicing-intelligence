# Interactive dashboard

Open `index.html` in a modern browser. The dashboard is fully self-contained, loads no external libraries, and transmits no data.

The reporting-month selector updates volume, month-over-month and year-over-year comparisons, year-to-date context, response metrics, narrative coverage, the trailing trend chart, and aggregate company and issue drilldowns for every complete selectable period. July 2026 is the default case-study state.

This public-review build includes aggregate data only. Complaint-level records, complaint IDs, and narrative excerpts are not packaged with the dashboard.

The interface is intentionally framed as an early-warning and issue-discovery product. It distinguishes public complaint volume from an exposure-adjusted rate and keeps partial-period, narrative-coverage, taxonomy, and interpretation limitations visible.
